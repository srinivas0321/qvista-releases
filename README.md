# QVista downloads

Installers for QVista, the IBM MQ queue browser for Mac and Windows.

This repository holds only the installers. The source code is in a separate private repository.

## Download

Open the [latest release](https://github.com/srinivas0321/qvista-releases/releases/latest) and download:

- **Mac:** `QVista-1.1.0.dmg`. Open it and drag QVista into Applications.
- **Windows:** `QVista-Setup-1.1.0.exe`. Run it and follow the steps.

Each file lists its SHA-256 checksum in the release notes, so you can check the download.
